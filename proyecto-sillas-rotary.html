Caso 01 · Sistema de campo

Sillas Rotary.

Implementación documentada

Una aplicación web mobile-first para sustituir formularios de papel por captura digital, fotografías y consulta trazable de expedientes.

01 · Problema

Registrar en campo sin perder el hilo del expediente.

La documentación pública describe un proceso sostenido por formularios físicos y transcripción posterior. Ese flujo dificulta conservar la relación entre datos socioeconómicos, solicitudes técnicas, medidas y fotografías.

Alcance de esta afirmación

El problema se toma de la documentación del repositorio. Este caso no publica una medición independiente de pérdida de información, tiempos o volumen de expedientes.

02 · Trabajo realizado

Diseñar el flujo y construir sus componentes.

  1. Captura socioeconómica

    Se implementó un formulario para registrar beneficiario, domicilio, tutores y datos del estudio.

  2. Solicitud técnica

    Se registran entorno de uso, información postural, medidas, observaciones y prioridad.

  3. Fotografías

    El sistema permite adjuntar una imagen y vincularla con la solicitud correspondiente.

  4. Trazabilidad

    La API relaciona usuarios, regiones, beneficiarios, estudios y solicitudes mediante identificadores y roles.

03 · Contexto

Una relación descrita con cautela.

El repositorio identifica el sistema como trabajo para capturistas de campo del programa Ecosistema VIDA UG y menciona a la Universidad de Guanajuato y Rotary 200 en ese contexto.

No presentamos esa mención como respaldo institucional general a Neuxora ni inferimos una alianza más amplia. La fuente verificable es la documentación pública del proyecto.

05 · Límites

El sistema existe. Su efecto todavía requiere medición.

  • No se publican métricas verificables de uso, ahorro de tiempo o reducción de errores.
  • No se presenta como dispositivo médico ni como sistema con validación clínica.
  • La disponibilidad de código y una URL de despliegue no demuestran adopción sostenida.
  • El repositorio conserva pendientes técnicos; el estado puede cambiar conforme avance el proyecto.
