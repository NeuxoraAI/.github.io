Cómo leer el índice

El estado importa.

Implementación

Sistema construido

Existe código o una interfaz que permite revisar el flujo descrito.

Prototipo

Hipótesis operativa

La herramienta permite probar una forma de trabajo, pero no se presenta como producto consolidado.

Efecto

Resultado no asumido

Sin un protocolo y datos de evaluación, no atribuimos mejoras organizacionales o clínicas al sistema.

Límites del índice

Código público es evidencia de implementación, no de adopción.

Los repositorios permiten revisar componentes, documentación y decisiones técnicas. No prueban por sí solos cuántas personas usaron un sistema, si cambió un proceso o si produjo un beneficio clínico.
