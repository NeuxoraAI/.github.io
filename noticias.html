Estructura editorial

Cada categoría responde algo distinto.

Caso
Explica un problema, el sistema construido, su contexto, la evidencia y los límites.
Experimento
Expone una pregunta, condiciones de comparación, resultados técnicos y alcance.
Método
Documenta una decisión de diseño o una forma reproducible de trabajar.
Publicación
Se reserva para artículos, preprints o reportes con una referencia estable. Aún no hay publicaciones formales listadas.
Criterio

No llenar el archivo con anuncios vacíos.

El Cuaderno crece cuando hay un proyecto, una comparación o un método que pueda revisarse. No inventa artículos, autores ni conclusiones para aparentar actividad.
